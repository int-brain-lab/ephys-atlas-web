IBL Ephys Atlas

Explore electrophysiology features and brain-wide analysis results.

This website provides a shared anatomical framework for exploring brain-wide data. Anatomical mappings, slice views, summary plots, and 3D visualization allow extracted features, analytical results, and user-supplied data to be viewed and compared consistently across brain regions.
